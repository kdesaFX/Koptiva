# Koptiva Releases

This public repository hosts compiled Windows x64 downloads for Koptiva. Development source is maintained separately in a private repository and is not included in these release downloads.

## Downloads

Published app builds appear on the [Releases page](https://github.com/kdesaFX/Koptiva-Releases/releases). The app's built-in updater checks the latest release here.

## Source archive contents

GitHub automatically offers source archives for public tags. This repository is intentionally limited to this README and release metadata, so those archives do not contain Koptiva application source. Release assets are compiled binaries and required third-party notices.
