## Install

Download `Koptiva.Installer.exe` from the [latest release](https://github.com/kdesaFX/Koptiva-Releases/releases/latest), run it, and choose a regular or portable installation. A regular installation can add Start menu and desktop shortcuts. Preview installers are unsigned, and Windows may show a User Account Control prompt because the installer can request administrator access.

## Automatic updates

Koptiva checks this repository for the latest release and downloads the installer when an update is available. The same installer is available directly from the Releases page.

## Source archive contents

GitHub’s automatic source archives contain only this README and the Koptiva logo. They do not contain application source code. Published releases contain the compiled installer and required third-party notices.
